# Emby 下载器

一个基于 Electron 的桌面客户端，连接 Emby / Jellyfin 服务器，浏览媒体库内容并下载。

## 功能

- **添加服务器**：支持多个 Emby / Jellyfin 服务器，通过地址 + 用户名 + 密码登录
- **双栏浏览**：
  - 左侧为「服务器 → 媒体库分组」两级树，点击服务器展开/收起分组，右键可移除服务器
  - 点击分组后，右侧显示该分组的内容列表（名称、类型、添加时间、大小），向下滚动自动加载更多（无限滚动）
- **搜索**：选中分组后通过顶栏搜索框搜索该分组内的内容（剧集库同时匹配剧名与单集名），结果同样无限滚动加载、右键下载；快捷键 Ctrl+F 聚焦搜索框，Esc 或 × 清除
- **剧集展开**：剧集库按「剧集 → 季 → 单集」分层展示，点击剧集/季即可展开或收起；右键剧集或季可一键下载其下全部单集
- **右键下载**：在内容列表中右键（或双击）即可加入下载队列
- **下载管理**：左侧底部「下载管理」打开下载面板，可查看进度、速度，取消任务、清空已完成记录
- **断点续传与重试**：下载写入 `.part` 临时文件，完成后自动改名为最终文件；连接中断/超时/服务器临时错误时自动退避重试（最多 4 次：2s/4s/8s/15s，从断点继续），失败或已取消的任务可手动点击「重试」，取消不会丢失已下载的部分
- **设置**：左侧底部「设置」可修改文件保存位置和同时下载数

## 运行

```bash
npm install
npm start
```

## 配置文件

配置（服务器、登录凭证、设置）保存在：

- Windows: `%APPDATA%/emby-downloader/config.json`
- macOS: `~/Library/Application Support/emby-downloader/config.json`
- Linux: `~/.config/emby-downloader/config.json`

## 说明

- 登录凭证（Access Token）以明文保存在本地配置文件中，请勿将配置文件外传
- 下载使用服务器的原始文件接口（`/Items/{Id}/Download`），需要服务器/账户允许下载权限
- 下载任务队列保存在内存中，应用退出后未完成的任务不会自动恢复
- 不同类型的媒体库只列出可直接下载的文件：电影库列电影、剧集库按剧集分组（点击展开季和单集）、音乐库列音轨，混合库排除纯文件夹
